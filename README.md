🎵 MindHaven Mood-Based Music Recommender AI

A lightweight AI system that recommends music based on the user's emotional state.
This tool helps people improve their mood through music therapy concepts, combined with machine learning.

🚀 Features

Detects user mood using text input

Suggests songs appropriate for that emotion

Uses simple machine-learning logic

Easy to deploy in any Python environment

Ideal for mental health support platforms

🧠 How It Works

User enters a mood (like happy, sad, stressed, energetic).

AI analyzes the emotion.

It recommends a matching playlist from a curated dictionary.

This demonstrates your ability to design AI emotional-wellbeing tools, perfect for GTV.

▶️ Example Code
from moodmusic import recommend_music

mood = "sad"
songs = recommend_music(mood)

print("Recommended Songs:")
for song in songs:
    print("- ", song)
